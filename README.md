# 宇宙実測ナビ

観測値や論文の値をもとに、地球から観測可能な宇宙までを3Dで旅するWebアプリです。ブラウザだけで動き、インストールは不要です。

## できること

- **境目のないズーム**：ホイールやピンチで縮小し続けると、7つのスケールを自動で切り替えながら進みます。切り替えの間も、同じ物理的な位置を保ちます。
  - 地球と近傍宇宙 → 太陽系 → 恒星近傍 → 天の川銀河 → 局所銀河群 → 宇宙の大規模構造 → 観測可能な宇宙
  - 「自動ズームアウト／ズームイン」ボタンで、自動でも往復できます。
- **実時刻の地球と太陽系**：次のものを日時から計算して表示します。
  - 世界地図（Natural Earth）
  - 地軸の傾き・自転・昼夜の境界
  - 月の位置と満ち欠け
  - 惑星の位置
- **ライブデータ（自動更新）**：人工衛星、飛行機、船舶（フィンランド周辺）、主要都市の天気、NASAの衛星画像を表示します。
- **ツアー**：地球、ISS、月、惑星、近くの恒星、銀河中心、アンドロメダ、銀河団を経て宇宙の果てまで、16か所を順に案内します。日本語の音声ガイドにも対応しています。
- **自由飛行**：秒速1mから光速まで速度を変えて移動できます。移動距離・経過時間・ローレンツ因子も表示します。
- **出典と確度の表示**：天体をタップすると、データと出典が出ます。各データには「観測値／推定値／模式図／仮説／ライブ」のラベルが付きます。
- **仮説モード**：「意識場（ゼロポイントフィールド）と脳の量子もつれ」を、科学的に未実証の芸術的イメージとして可視化します。

## 公開方法（GitHub Pages）

1. GitHubで新しいリポジトリを作ります（例：`cosmos-navi`）。
2. このフォルダの `index.html`・`README.md`・`THIRD_PARTY_NOTICES.md`・`.nojekyll` をアップロードします。
3. **Settings → Pages** で、「Deploy from a branch」・ブランチ `main`・フォルダ `/ (root)` を選んで保存します。
4. 数分後に `https://<ユーザー名>.github.io/cosmos-navi/` で見られるようになります。

ライブデータは外部サイトから直接取得します。そのため、claude.ai 上のプレビューでは動きません（外部への通信が制限されるため）。GitHub Pages や自分のサーバーで公開すると動作します。

## ライブデータの提供元と利用条件

**利用条件は変わることがあります。商用利用（会社のサイト、収益化した動画・サービスなど）の場合は、必ず各サービスの最新の規約を確認してください。**

| データ | 提供元 | 更新間隔（本アプリ） | 主な注意点 |
|---|---|---|---|
| 人工衛星 | [CelesTrak](https://celestrak.org/) の軌道要素（TLE）を [satellite.js](https://github.com/shashwatak/satellite-js) の SGP4 で計算 | 軌道要素は2時間ごと（ブラウザに保存）、位置は毎秒計算 | 同じデータを短い間隔で何度も取得しないよう求められています |
| 飛行機 | [OpenSky Network](https://opensky-network.org/) REST API（匿名） | 10分ごと、間は速度と方位で推定 | 匿名利用は1日の回数に上限があります。利用は研究・非商用目的に限られているとの理解です（要確認） |
| 船舶 | [Fintraffic Digitraffic](https://www.digitraffic.fi/) Marine AIS | 1分ごと | フィンランド周辺（バルト海）の船だけが対象です。CC BY 4.0（出典表示が必要） |
| 天気 | [Open-Meteo](https://open-meteo.com/) | 15分ごと | 無料版は非商用向けです。商用には有料プランが必要です。データは CC BY 4.0 |
| 衛星画像 | [NASA GIBS](https://www.earthdata.nasa.gov/engage/open-data-services-software/earthdata-developer-portal/gibs-api)（VIIRS 真色合成） | 表示時に1回 | 前日（UTC）の合成画像で、リアルタイムの雲ではありません |

世界の船舶をまとめて見られる、無料でキー不要・ブラウザから直接取得できるAPIは見つかりませんでした。そのため、船舶はフィンランド周辺のみの対応です。

## 正確性について

- 数値は NASA/JPL、Planck 2018、GRAVITY、査読論文などの公表値です。各天体の詳細パネルに出典を載せています。
- 惑星の位置はJPLの近似式、月の位置は低精度式（約0.3°）によるもので、高精度の天体暦ではありません。
- 人工衛星の位置は、軌道要素の元期から日数がたつほど誤差が増えます。
- 飛行機と船は、最後に受信した位置から現在位置を推定（外挿）しています。
- 渦状腕の形、宇宙の網目構造、CMBの模様は模式図です。
- 隣り合うスケールの境目では位置を保って切り替えますが、天の川銀河の向きと黄道座標の対応は簡略化しています。
- 探査機の現在距離、最遠方銀河の記録などは推定値を含みます。
- 質量のある物体は光速に到達できません。自由飛行の「光速」は仮想の設定です。
- 仮説モードの内容に、科学的な裏付けはありません。
