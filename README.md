# 宇宙実測ナビ

観測データに基づく3D宇宙モデルで、地球から「観測可能な宇宙」まで旅するWebアプリです。ブラウザだけで動き、インストールは不要です。

数値・位置には出典と確度（観測値／推定値／模式図／仮説／軌道要素からの計算）を付けています。すべての形・位置・色を直接測定したものではありません。

## できること

- **境目のないズーム**：ホイールやピンチで縮小し続けると、7つのスケールを自動で切り替えます。切り替えの前後で同じ物理的な位置を保ちます。
  - 地球と近傍宇宙 → 太陽系 → 恒星近傍 → 天の川銀河 → 局所銀河群 → 宇宙の大規模構造 → 観測可能な宇宙
  - 設定の「自動ズームアウト／ズームイン」でも往復できます。
- **入口画面**：「90秒で宇宙旅行」「行き先を選ぶ」「自由に飛ぶ」から始められます。2回目以降は「続きから」も選べます。音声は自動では鳴りません。
- **星空カタログ**（v7で追加）：名前の付いた星・星座・星雲・星団・銀河・準惑星・彗星・衛星を収録しました。
  - 恒星：約4万700個（主に8等級より明るい星と、50光年以内の星）。そのうち固有名のある451個は名前で探せます。恒星近傍スケールでは、年周視差による距離で3D配置し、見かけの明るさはカメラからの距離で計算し直します。
  - 星座：IAUの88星座すべて。星座線は「天球（地球から見た形）」「実際の3D位置」「オフ」を設定で切り替えられます。3D位置にすると、星座の星どうしの距離がばらばらなことが分かります。
  - 星雲・星団・銀河：NGC・IC・メシエ天体など約1万2,200個。メシエ天体は110個すべて検索できます。
    - 代表的な47天体（すばる、オリオン大星雲、ヘルクレス座球状星団など）は、文献の距離（概数）で3D配置しています。
    - 赤方偏移が分かる銀河（約1万個）は、ハッブル則で求めた距離の目安で「宇宙の大規模構造」に点として配置しています。
    - 距離のデータがない天体は、太陽系から見た方向（天球）にだけ表示します。
  - 小天体：準惑星（冥王星・ケレス・エリスなど5個）、小惑星（イトカワ・リュウグウ・ベンヌなど）、太陽系外縁天体、彗星（ハレー彗星など6個）、恒星間天体（2個）の計25個。表示日時の位置を軌道要素から計算します。
  - 衛星：火星・木星・土星・天王星・海王星・冥王星の主な衛星24個。
  - 名前のラベルは重ならないよう、明るい天体から順に一部だけ表示します。すべて「行き先」で検索できます。
- **行き先検索**：日本語名・英語名・別名・カタログ番号で探せます（例：土星／Saturn、アンドロメダ／M31、ベテルギウス／HIP 27989、オリオン座／Ori、M42、NGC 7000、ハレー彗星、タイタン）。
  - 方向だけが分かる天体（星座、距離データのない星雲など）を選ぶと、太陽の近くからその方向を見る視点に移ります。
  - 「移動」はカメラ演出で、実際の航行時間ではありません。
  - 「詳細」は移動せずに情報だけを表示します。
  - ☆でお気に入りに登録できます。
- **世界のライブカメラ**（v8で追加）：世界各地の定点ライブカメラ98か所を地球上にピンで表示し、サイト内のウィンドウで視聴できます。
  - 地球観測レイヤーの「ライブカメラ」をオンにすると、ピンと地域別の一覧が出ます。名前を押すと視聴ウィンドウが開きます。ウィンドウはドラッグで動かせ、同時に4つまで開けます。「行き先」で「ライブカメラ」や地名でも探せます。
  - 映像は配信者がYouTubeで公開しているライブ配信で、YouTube公式の埋め込みプレーヤー（youtube-nocookie.com）で表示します。音声は最初オフです。
  - 初期状態はオフです。視聴ウィンドウを開くまで、YouTubeとは通信しません。
  - 情報パネルには、配信者、確認時の配信タイトル、現地が昼か夜か（太陽高度の計算値）を表示します。
  - 掲載したのは、2026年10月17日に「公開されている」「埋め込みが許可されている」（YouTubeのoEmbedで確認）「ライブ配信である」の3点を確認できたものだけです。配信は配信者の都合で終了・差し替えされることがあり、その場合は再生できません。季節限定の配信（クマ、アルバトロスなど）や、配信時間が決まっているもの（水族館など）もあります。
- **天体の写真・イメージ図**：天体を選ぶと、情報パネルの上部に画像が出ます。画像の種類（実写／観測画像／想像図／イメージ図）とクレジットも表示します。
  - 38種類はNASA Image and Video Libraryの画像です（v7で、すばる、オリオン大星雲、わし星雲、らせん状星雲、子持ち銀河、ソンブレロ銀河、冥王星、ハレー彗星、ベスタ、トリトンを追加）。
  - 新しく追加した星・星座・星雲などの多くは、種類ごとのイメージ図（このアプリで描画）です。星座は、星座線データから描いた図を表示します。
  - 権利を確認できる写真がない天体は、このアプリが描いた「イメージ図」です。写真ではないことを明記しています。
- **地球へ戻る**：ツアー・自由飛行・自動ズームを止めて、地球の標準視点へ戻ります。日時は変えません。
- **現在地バー**：今いるスケール、選択中の天体、操作モード、時刻の状態を画面上部に表示します。
- **ツアー**：4コースあります。字幕が主で、日本語の音声ガイドは任意です。一時停止・再開・読み直し・途中からの再開ができます。
  - はじめての宇宙旅行
  - 太陽系の絶景
  - 光でも遠い宇宙
  - 完全ツアー（16地点）
- **体験ラボ**
  - 光と月：地球と月の間の光の移動（実時間と10倍スロー）
  - 火星通信：表示日時の瞬間距離を固定した近似で、通信の待ち時間を表示
  - 相対論の時計：光速未満の等速運動で、外部の時計と船内の時計を比較
  - 大きさ比較：比較用に整列した図と、「太陽を直径1 mにすると」の換算表
- **自由飛行（観察カメラ）**：宇宙船（光速未満）と、光（v = c、教材）を切り替えられます。光には船内時計を定義できないため「適用外」と表示します。
- **写真モード**：16:9・9:16・1:1でPNGを保存できます。画像には表示日時、「実写ではない3D表示」である旨、地図や軌道要素の出典が入ります。
- **共有リンク**：表示中のスケール・天体・日時・視点をリンクにできます。個人情報や位置情報は含みません。
- **端末内の保存**：お気に入り、訪問履歴、ツアー記録、ミッション、設定を保存します。JSONで書き出し・読み込みができます。
- **画質設定**：自動・軽量・標準・高画質。
- **想像ラボ（仮説アート）**：「意識場と脳の量子もつれ」という未実証の仮説を、芸術的イメージとして描いたモードです。通常の宇宙探索とは別の入口（設定）から開きます。

## 公開方法（GitHub Pages）

既存のリポジトリに、変更したファイルを**同じ名前で上書き**するだけです。

1. `UPLOAD_ONLY.zip` を解凍します。中身は `index.html`・`README.md`・`THIRD_PARTY_NOTICES.md` の3つです。
2. GitHubのリポジトリ画面で「Add file → Upload files」を選び、3つのファイルをまとめてドラッグして、Commit します。
3. 数分後に `https://<ユーザー名>.github.io/cosmos-navi/` に反映されます。

アイコン類（`favicon.ico` など）、`site.webmanifest`、`.nojekyll` は変更していないので、そのまま残してください。

### 更新が見えないとき

ブラウザが古いファイルを覚えていることがあります。

- **パソコン**：`Ctrl + Shift + R`（Macは `Cmd + Shift + R`）で強制再読み込みします。
- **スマートフォン**：ページを閉じて開き直します。それでも変わらない場合は、ブラウザの閲覧データ（キャッシュ）を消去します。

### 元に戻す方法

- **GitHubの画面から**：リポジトリの「Commits」を開き、更新前のコミットにある3つのファイルを取得します。それを同じ名前で再アップロードして Commit すれば、元に戻ります。
- **Gitを使う場合**：`git revert` で該当コミットを取り消せます。

各データには取得日時を表示しています。直接の観測値と、計算値・数値予報は区別しています。

- 衛星の位置は、軌道要素から計算した値です。

- 船舶は、表示日時が現在から15分以上ずれると表示しません。
- 衛星画像も、表示日時が現在でないときは表示しません。

## 正確性と表現について

- **惑星の位置**：JPL公表の近似要素（Standish）を基に、平均黄経以外の経年変化を省略した簡略計算です。1800〜2050年の範囲で使い、範囲外では「適用範囲外（模式表示）」と表示します。精密な位置は [JPL Horizons](https://ssd.jpl.nasa.gov/horizons/) で確認してください。
- **月の位置**：低精度の式（約0.3°）で計算しています。
- **恒星**：距離は主にヒッパルコス衛星の年周視差によるものです（HYG v4.1経由）。遠い星ほど誤差が大きく、数百光年を超える星は「推定値」と表示します。Gaiaの最新値とは異なることがあります。恒星の固有運動（年月による位置の変化）は計算していません（J2000の位置）。
- **星座線**：結び方は流儀によって異なります。このアプリはd3-celestialのデータを使っています。星座の境界線は表示していません。
- **星雲・星団・銀河の距離**：3D配置した47天体の距離は、公表されている代表値の概数です（文献によって差があります）。銀河の距離の目安は、赤方偏移からハッブル則（H₀=67.4 km/s/Mpc、他のスケールと共通）で求めています。近い銀河ほど、銀河自身の動きの影響で誤差が大きくなります。
- **小天体**：JPLの軌道要素から二体問題で計算した概略の位置です。惑星による摂動は計算していないため、元期から離れるほどずれます。彗星の尾の向きと長さは模式です。
- **衛星**：位置は平均軌道要素からの概算で、軌道面は簡略化しています。天王星・海王星・冥王星の衛星は公転の位置（位相）のデータを持っていないため、模式です。
- **衛星の位置**：SGP4で計算しています。結果のTEME座標は、黄道座標へ簡略に変換しています。
- **模式図**：渦状腕の形、宇宙の網目構造、CMBの模様、木星・土星の縞と環の濃淡は模式です。土星の環の各区分の半径は観測値に基づいています。
- **宇宙論スケール**：Planck 2018のΛCDMパラメータで計算しています。「観測可能な宇宙」の半径（共動距離）は、宇宙全体の端ではありません。
- **自由飛行**：天体の時刻を進めない観察カメラです。距離・時間の表示は「選んだ速さで同じ距離を進んだ場合」の参考値です。
- **光速**：質量のある宇宙船は光速に到達できません。
- **ネット接続**：ライブラリとフォントを外部（cdnjs・jsDelivr・Google Fonts）から、天体の写真をNASA（images-assets.nasa.gov）から読み込みます。そのため、オフラインでは動きません。写真を読み込めないときは、その旨を表示します。

## 動作環境

WebGLに対応したブラウザ（最新のChrome・Edge・Safari・Firefox）が必要です。天体データを含むため、`index.html` は約2 MBです。通信の遅い環境では、最初の表示に時間がかかることがあります。WebGLやライブラリを読み込めない場合は、原因の案内と、文章版の天体一覧を表示します。
