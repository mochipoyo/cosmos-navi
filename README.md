# 宇宙実測ナビ

観測データに基づく3D宇宙モデルで、地球から「観測可能な宇宙」まで旅するWebアプリです。ブラウザだけで動き、インストールは不要です。

数値・位置には出典と確度（観測値／推定値／模式図／仮説／軌道要素からの計算）を付けています。すべての形・位置・色を直接測定したものではありません。

## できること

- **境目のないズーム**：ホイールやピンチで縮小し続けると、7つのスケールを自動で切り替えます。切り替えの前後で同じ物理的な位置を保ちます。
  - 地球と近傍宇宙 → 太陽系 → 恒星近傍 → 天の川銀河 → 局所銀河群 → 宇宙の大規模構造 → 観測可能な宇宙
  - 設定の「自動ズームアウト／ズームイン」でも往復できます。
- **入口画面**：「90秒で宇宙旅行」「行き先を選ぶ」「自由に飛ぶ」から始められます。2回目以降は「続きから」も選べます。音声は自動では鳴りません。
- **星空カタログ**（v7で追加）：名前の付いた星・星座・星雲・星団・銀河・準惑星・彗星・衛星を収録しました。
  - 恒星：約4万700個（主に8等級より明るい星と、50光年以内の星）。そのうち固有名のある451個は名前で探せます。恒星近傍スケールでは、年周視差による距離で3D配置し、見かけの明るさはカメラからの距離で計算し直します。
  - 星座：IAUの88星座すべて。星座線は「天球（地球から見た形）」「実際の3D位置」「オフ」を設定で切り替えられます。3D位置にすると、星座の星どうしの距離がばらばらなことが分かります。
  - 星雲・星団・銀河：NGC・IC・メシエ天体など約1万2,200個。メシエ天体は110個すべて検索できます。
    - 代表的な47天体（すばる、オリオン大星雲、ヘルクレス座球状星団など）は、文献の距離（概数）で3D配置しています。
    - 赤方偏移が分かる銀河（約1万個）は、ハッブル則で求めた距離の目安で「宇宙の大規模構造」に点として配置しています。
    - 距離のデータがない天体は、太陽系から見た方向（天球）にだけ表示します。
  - 小天体：準惑星（冥王星・ケレス・エリスなど5個）、小惑星（イトカワ・リュウグウ・ベンヌなど）、太陽系外縁天体、彗星（ハレー彗星など6個）、恒星間天体（2個）の計25個。表示日時の位置を軌道要素から計算します。
  - 衛星：火星・木星・土星・天王星・海王星・冥王星の主な衛星24個。
  - 名前のラベルは重ならないよう、明るい天体から順に一部だけ表示します。すべて「行き先」で検索できます。
- **行き先検索**：日本語名・英語名・別名・カタログ番号で探せます（例：土星／Saturn、アンドロメダ／M31、ベテルギウス／HIP 27989、オリオン座／Ori、M42、NGC 7000、ハレー彗星、タイタン）。
  - 方向だけが分かる天体（星座、距離データのない星雲など）を選ぶと、太陽の近くからその方向を見る視点に移ります。
  - 「移動」はカメラ演出で、実際の航行時間ではありません。
  - 「詳細」は移動せずに情報だけを表示します。
  - ☆でお気に入りに登録できます。
- **世界のライブカメラ**：世界各地の定点ライブカメラ97か所を地球上のピンと一覧で表示し、サイト内の視聴ウィンドウで見られます。
  - 地球観測レイヤーの「ライブカメラ」をオンにすると、ピンと一覧が出ます。ピンは地球の自転に合わせて動き、地球の裏側のピンは見えなくなります。
  - ピンの色は配信の状態です。赤は配信中、灰色はオフライン、黄色は未確認です。
  - 一覧では、国・都市・地点の名前で検索できます。「配信中のみ」の絞り込みと、☆によるお気に入り登録もできます。「行き先」の検索でも、国名や都市名でカメラを探せます。
  - 視聴ウィンドウはドラッグで動かせます。パソコンでは同時に4つ、スマートフォンでは1つまで開けます。
    - 自動再生は常に1つだけです。新しく再生すると、ほかのウィンドウは一時停止します。
    - 開いていない地点のプレーヤーは読み込みません。
  - ウィンドウと情報パネルには、配信状態、現地の時刻（タイムゾーン）、現地が昼か夜か（太陽高度の計算値）を表示します。
  - 再生できないときは、理由を表示します。YouTubeのエラー100・101・150・153・2・5などに対応しています。あわせて、次の案内を出します。
    - 「YouTubeで開く」
    - 「配信者のチャンネル」
    - 近くのカメラ
    - 単独で配信しているチャンネルの場合は「チャンネルの現在のライブを試す」
  - 各ウィンドウの「診断ログ」と、ブラウザの開発者ツールのコンソール（`[livecam]` で始まる行）で、読み込みとエラーの経過を確認できます。
  - **地球ライブツアー**：配信中のカメラのうち、いま昼の場所を東から西へ45秒ずつ巡ります（最大10か所）。
  - 初期状態はオフです。視聴ウィンドウを開くまで、YouTubeとは通信しません。映像は YouTube 公式の埋め込みプレーヤー（youtube-nocookie.com）で表示し、映像の保存や再配信はしていません。
  - **配信状態の自動確認**：GitHub Actions が2時間ごとに YouTube Data API で確認し、`livecams.json` を更新します。
    - APIキーは GitHub の Secrets に置きます。公開されるファイルやブラウザには含まれません。
    - 設定方法は下の「ライブカメラの自動更新を設定する」を参照してください。
    - 設定しない場合も、手動で確認した時点の一覧から、どのカメラも手動で再生できます。この場合、状態は「未確認」と表示されます。
- **天体の写真・イメージ図**：天体を選ぶと、情報パネルの上部に画像が出ます。画像の種類（実写／観測画像／想像図／イメージ図）とクレジットも表示します。
  - 38種類はNASA Image and Video Libraryの画像です（v7で、すばる、オリオン大星雲、わし星雲、らせん状星雲、子持ち銀河、ソンブレロ銀河、冥王星、ハレー彗星、ベスタ、トリトンを追加）。
  - 新しく追加した星・星座・星雲などの多くは、種類ごとのイメージ図（このアプリで描画）です。星座は、星座線データから描いた図を表示します。
  - 権利を確認できる写真がない天体は、このアプリが描いた「イメージ図」です。写真ではないことを明記しています。
- **地球へ戻る**：ツアー・自由飛行・自動ズームを止めて、地球の標準視点へ戻ります。日時は変えません。
- **現在地バー**：今いるスケール、選択中の天体、操作モード、時刻の状態を画面上部に表示します。
- **ツアー**：4コースあります。字幕が主で、日本語の音声ガイドは任意です。一時停止・再開・読み直し・途中からの再開ができます。
  - はじめての宇宙旅行
  - 太陽系の絶景
  - 光でも遠い宇宙
  - 完全ツアー（16地点）
- **体験ラボ**
  - 光と月：地球と月の間の光の移動（実時間と10倍スロー）
  - 火星通信：表示日時の瞬間距離を固定した近似で、通信の待ち時間を表示
  - 相対論の時計：光速未満の等速運動で、外部の時計と船内の時計を比較
  - 大きさ比較：比較用に整列した図と、「太陽を直径1 mにすると」の換算表
- **自由飛行（観察カメラ）**：宇宙船（光速未満）と、光（v = c、教材）を切り替えられます。光には船内時計を定義できないため「適用外」と表示します。
- **写真モード**：16:9・9:16・1:1でPNGを保存できます。画像には表示日時、「実写ではない3D表示」である旨、地図や軌道要素の出典が入ります。
- **共有リンク**：表示中のスケール・天体・日時・視点をリンクにできます。個人情報や位置情報は含みません。
- **端末内の保存**：お気に入り、訪問履歴、ツアー記録、ミッション、設定を保存します。JSONで書き出し・読み込みができます。
- **画質設定**：自動・軽量・標準・高画質。
- **想像ラボ（仮説アート）**：「意識場と脳の量子もつれ」という未実証の仮説を、芸術的イメージとして描いたモードです。通常の宇宙探索とは別の入口（設定）から開きます。

## 公開方法（GitHub Pages）

ZIPを解凍した `upload-to-github` フォルダの中身を、リポジトリに同じ名前・同じ場所でアップロードします。手順は、次の「ライブカメラの自動更新を設定する」の「6. ファイルをアップロードする」にまとめています。

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（上書き） |
| `livecams.json` | ライブカメラの管理データ（新規）。自動更新で書き換わります |
| `README.md`・`THIRD_PARTY_NOTICES.md` | 説明とライセンス表記（上書き） |
| `scripts/update-livecams.mjs` | 配信状態を確認するプログラム（新規） |
| `.github/workflows/update-livecams.yml` | GitHub Actions の設定（新規） |

アイコン類（`favicon.ico` など）、`site.webmanifest`、`.nojekyll` は変更していないので、そのまま残してください。

## ライブカメラの自動更新を設定する（初心者向け）

自動更新を使わなくても、サイトは動きます。その場合は「6. ファイルをアップロードする」だけ行ってください。Google Cloud と GitHub の画面の表記は変わることがあります。見つからないときは、似た名前の項目を探してください。

### 1. Google Cloud で YouTube Data API を有効にする

1. https://console.cloud.google.com/ を開き、Google アカウントでログインします。初めての場合は、利用規約に同意します。
2. 画面上部のプロジェクト選択から「新しいプロジェクト」を選び、名前（例：`cosmos-navi`）を付けて作成します。
3. 作成したプロジェクトが選ばれていることを確認し、左のメニューから「APIとサービス」→「ライブラリ」を開きます。
4. 「YouTube Data API v3」を検索して開き、「有効にする」を押します。

YouTube Data API は無料の利用枠の範囲で使えます。このアプリの設定では、枠を超えないように回数を抑えています。費用やお支払い情報の登録を求められた場合は、内容を確認してから判断してください。

### 2. APIキーを発行する

1. 「APIとサービス」→「認証情報」を開きます。
2. 「認証情報を作成」→「APIキー」を選びます。
3. 表示されたキーを控えます。このキーは他人に見せないでください。チャットやSNSに貼ったり、ファイルに書いて公開したりしないでください。
4. 作成したキーの編集画面で、「APIの制限」を「キーを制限」にし、「YouTube Data API v3」だけを選んで保存します。
   - 「アプリケーションの制限」は「なし」のままにします。GitHub Actions のサーバーは IP アドレスが決まっていないためです。

### 3. GitHub Secrets に登録する

1. GitHub で `cosmos-navi` リポジトリを開き、「Settings」を押します。
2. 左のメニューから「Secrets and variables」→「Actions」を開きます。
3. 「New repository secret」を押します。
4. Name に `YT_API_KEY`（大文字。この通りに入力）、Secret に手順2のキーを貼り付けて、「Add secret」を押します。

登録したキーは、あとから画面で見ることはできません。キーを変えるときは「Update」で上書きします。

### 4. GitHub Actions を使えるようにする

1. リポジトリの「Actions」タブを開きます。
2. 「I understand my workflows, go ahead and enable them」などのボタンが出たら押します。何も出なければ、そのままで使えます。
3. Settings →「Actions」→「General」の「Workflow permissions」が「Read and write permissions」になっているか確認します。
   - ワークフローの中で書き込み権限を指定しているので、通常は変更不要です。
   - 組織の設定などで書き込みが禁止されていると、`livecams.json` を保存する手順だけが失敗します。サイトの公開は続きます。

### 5. GitHub Pages の公開方法を「GitHub Actions」に変える（必要です）

自動更新したデータを公開サイトに反映するには、この変更が必要です。GitHub Actions が `GITHUB_TOKEN` で行ったコミットでは、「ブランチから公開」の方式の再ビルドが動かないためです（GitHub公式ドキュメントに記載）。

1. Settings → 左のメニューの「Pages」を開きます。
2. 「Build and deployment」の「Source」を「Deploy from a branch」から「GitHub Actions」に変えます。
3. 表示されるテンプレートの案内（「Static HTML」など）は使いません。このZIPのワークフローを使います。

**順番の注意**：先に「6. ファイルをアップロードする」を済ませてから、この設定を変えてください。設定を変えてから最初のワークフローが成功するまでは、公開サイトは前回の内容のままです（消えることはありません）。元に戻すときは、Source を「Deploy from a branch」（main / root）に戻します。

### 6. ファイルをアップロードする

1. ZIPを解凍します。`upload-to-github` フォルダを開きます。
2. リポジトリの画面で「Add file」→「Upload files」を押します。
3. 次のものをまとめてドラッグし、「Commit changes」を押します。
   - `index.html`
   - `livecams.json`
   - `README.md`
   - `THIRD_PARTY_NOTICES.md`
   - `scripts` フォルダ（フォルダごと）
4. ワークフローのファイルは、次の方法で作ります。`.github` のように「.」で始まるフォルダは、パソコンで見えないことやドラッグで送れないことがあるためです。
   1. 「Add file」→「Create new file」を押します。
   2. ファイル名の欄に `.github/workflows/update-livecams.yml` と入力します。「/」を入力すると、フォルダが自動で作られます。
   3. ZIPの中の `workflow-for-copy-paste.yml.txt` をテキストエディタ（メモ帳やテキストエディット）で開き、全文をコピーして本文の欄に貼り付けます。
   4. 「Commit changes」を押します。

アップロードすると、ワークフローが自動で動き始めます（main への変更がきっかけ）。

### 7. 正常に動いているか確かめる

1. 「Actions」タブで「Update live cameras and deploy site」の実行結果が緑のチェックになっているか確認します。
   - 赤い×のときは、実行を開いてエラーの出た手順を確認します。
   - 手動で動かすときは、ワークフロー名を選んで「Run workflow」を押します。
2. 「Check live camera status」手順のログの最後に、`quota today: units …` と `… live of 97` が出ていれば、APIでの確認ができています。
   - `APIキー（YT_API_KEY）が設定されていない` と出る場合は、手順3の名前を確認します。
3. リポジトリの `livecams.json` が「github-actions[bot]」によって更新されていれば、保存もできています（状態に変化がなければ更新されません）。
4. 公開サイトを開いて「ライブカメラ」をオンにし、一覧の上の行を確認します。「自動確認：正常（日時）」と「データ：livecams.json」と表示されていれば、反映されています。
5. ピンが赤（配信中）・灰色（オフライン）で表示され、配信中のカメラを開くと再生されることを確認します。

### 自動更新のしくみと注意

- **実行のタイミング**：2時間ごと（毎時17分）と、main ブランチが変更されたときです。GitHub の混雑で遅れることがあります。
- **videos.list**：登録中の全動画の状態を、50本ずつまとめて確認します。ライブ配信中か、埋め込みが許可されているか、終了・非公開・削除されていないかを調べます。
- **search.list**：配信が終わったカメラについて、同じチャンネルの「配信中・埋め込み可」のライブを探します。
  - 同じ場所の配信だと判断できたときだけ、自動で差し替えます。判断の基準は、タイトルが元の配信とよく似ていることです（配信者名の語は除いて比べます）。
  - 別の都市かもしれない配信は割り当てず、`livecams.json` の `candidates` に候補として残します。
  - 候補で問題ないと確認できたら、そのカメラの `videoId` を書き換えてアップロードしてください。
- **利用枠**：2026年10月時点の公式ドキュメントでは、videos.list が1回1ユニット（共通枠1日10,000ユニット）、search.list が専用枠で1日100回までです。このプログラムの抑え方は次のとおりです。上限の値は変わることがあります。
  - 共通枠は8,000ユニット、search.list は80回までに抑えます。
  - search.list は、1回の実行で6チャンネルまでにしています。
  - 同じカメラを再検索するのは12時間ごとです。
- **上限超過・障害のとき**：前回の結果を残したまま、サイトの公開は続けます。
  - 確認できていない状態は、時間がたつとブラウザで「未確認」と表示されます。配信中の結果は4時間、オフラインの結果は24時間を過ぎると「未確認」になります。
- **APIキー**：ワークフローの実行中だけ環境変数として渡します。`livecams.json`・`index.html`・ログには書き出しません。
- **カメラの追加・削除**：`livecams.json` の `cams` を編集してアップロードします。`id`、`name`、`lat`、`lon`、`tz`、`videoId`、`author` などの項目は、既存の項目と同じ形で書いてください。

### 更新が見えないとき

ブラウザが古いファイルを覚えていることがあります。

- **パソコン**：`Ctrl + Shift + R`（Macは `Cmd + Shift + R`）で強制再読み込みします。
- **スマートフォン**：ページを閉じて開き直します。それでも変わらない場合は、ブラウザの閲覧データ（キャッシュ）を消去します。

### 元に戻す方法

- **GitHubの画面から**：リポジトリの「Commits」を開き、更新前のコミットにある `index.html`・`README.md`・`THIRD_PARTY_NOTICES.md` を取得します。それを同じ名前で再アップロードして Commit します。
  - 自動更新もやめる場合は、`.github/workflows/update-livecams.yml` を削除します。
  - あわせて、Settings → Pages の Source を「Deploy from a branch」（main / root）に戻します。
- **Gitを使う場合**：`git revert` で該当コミットを取り消せます。

## 外部データの提供元と利用状況

利用条件は変わることがあります。商用利用（会社のサイト、宣伝、収益化した発信など）の場合は、公開前に各サービスの最新の規約を確認してください。2026年10月13日に確認した内容に基づいています。

| データ | 提供元 | 状態 | 理由・条件 |
|---|---|---|---|
| 人工衛星の軌道要素 | [CelesTrak](https://celestrak.org/NORAD/documentation/gp-data-formats.php)（OMM/JSON形式） | 有効 | 公式の取得方針に従います。同じデータの取得は2時間に1回までで、ブラウザ内に保存して再利用します。HTTP 403/404の後は自動で再要求しません。利用規約の全文は未確認です |

## 正確性と表現について

- **惑星の位置**：JPL公表の近似要素（Standish）を基に、平均黄経以外の経年変化を省略した簡略計算です。1800〜2050年の範囲で使い、範囲外では「適用範囲外（模式表示）」と表示します。精密な位置は [JPL Horizons](https://ssd.jpl.nasa.gov/horizons/) で確認してください。
- **月の位置**：低精度の式（約0.3°）で計算しています。
- **恒星**：距離は主にヒッパルコス衛星の年周視差によるものです（HYG v4.1経由）。遠い星ほど誤差が大きく、数百光年を超える星は「推定値」と表示します。Gaiaの最新値とは異なることがあります。恒星の固有運動（年月による位置の変化）は計算していません（J2000の位置）。
- **星座線**：結び方は流儀によって異なります。このアプリはd3-celestialのデータを使っています。星座の境界線は表示していません。
- **星雲・星団・銀河の距離**：3D配置した47天体の距離は、公表されている代表値の概数です（文献によって差があります）。銀河の距離の目安は、赤方偏移からハッブル則（H₀=67.4 km/s/Mpc、他のスケールと共通）で求めています。近い銀河ほど、銀河自身の動きの影響で誤差が大きくなります。
- **小天体**：JPLの軌道要素から二体問題で計算した概略の位置です。惑星による摂動は計算していないため、元期から離れるほどずれます。彗星の尾の向きと長さは模式です。
- **衛星**：位置は平均軌道要素からの概算で、軌道面は簡略化しています。天王星・海王星・冥王星の衛星は公転の位置（位相）のデータを持っていないため、模式です。
- **衛星の位置**：SGP4で計算しています。結果のTEME座標は、黄道座標へ簡略に変換しています。
- **模式図**：渦状腕の形、宇宙の網目構造、CMBの模様、木星・土星の縞と環の濃淡は模式です。土星の環の各区分の半径は観測値に基づいています。
- **宇宙論スケール**：Planck 2018のΛCDMパラメータで計算しています。「観測可能な宇宙」の半径（共動距離）は、宇宙全体の端ではありません。
- **自由飛行**：天体の時刻を進めない観察カメラです。距離・時間の表示は「選んだ速さで同じ距離を進んだ場合」の参考値です。
- **光速**：質量のある宇宙船は光速に到達できません。
- **ネット接続**：ライブラリとフォントを外部（cdnjs・jsDelivr・Google Fonts）から、天体の写真をNASA（images-assets.nasa.gov）から、ライブカメラの映像をYouTubeから読み込みます。そのため、オフラインでは動きません。写真を読み込めないときは、その旨を表示します。

## 動作環境

WebGLに対応したブラウザ（最新のChrome・Edge・Safari・Firefox）が必要です。天体データを含むため、`index.html` は約2 MBです。通信の遅い環境では、最初の表示に時間がかかることがあります。WebGLやライブラリを読み込めない場合は、原因の案内と、文章版の天体一覧を表示します。
