# 宇宙実測ナビ

観測値や論文の値をもとに、太陽系から観測可能な宇宙までを3Dで旅するWebアプリです。ブラウザだけで動き、インストールは不要です。

## できること

- **6つのスケール**：太陽系 → 恒星近傍 → 天の川銀河 → 局所銀河群 → 宇宙の大規模構造 → 観測可能な宇宙
- **実時刻の太陽系**：惑星の位置をJPLの近似軌道要素で、今日の日付から計算します。
- **地球の再現**：実際の世界地図（Natural Earth）を表示します。地軸の傾き・自転・昼夜の境界も日時から計算します。
- **自由飛行**：秒速1mから光速まで速度を変えて移動できます。移動距離・経過時間・ローレンツ因子も表示します。
- **出典と確度の表示**：天体をタップすると、データと出典が出ます。各データには「観測値／推定値／模式図／仮説」のラベルが付きます。
- **仮説モード**：「意識場（ゼロポイントフィールド）と脳の量子もつれ」を、科学的に未実証の芸術的イメージとして可視化します。

## 公開方法（GitHub Pages）

1. GitHubで新しいリポジトリを作ります（例：`cosmos-navi`）。
2. このフォルダの `index.html`・`README.md`・`THIRD_PARTY_NOTICES.md`・`.nojekyll` をアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Source** を「Deploy from a branch」にし、ブランチ `main`・フォルダ `/ (root)` を選んで保存します。
5. 数分後に `https://<ユーザー名>.github.io/cosmos-navi/` で見られるようになります。

`index.html` をダブルクリックしてパソコンで直接開くこともできます。ただしライブラリとフォントをCDNから読み込むため、インターネット接続が必要です。

## 操作

| 操作 | パソコン | スマホ |

| 視点の回転・拡大 | ドラッグ／ホイール | ドラッグ／ピンチ |

## 正確性について

- 数値は NASA/JPL、Planck 2018、GRAVITY、査読論文などの公表値です。各天体の詳細パネルに出典を載せています。
- 惑星の位置はJPLの近似式によるもので、高精度の天体暦ではありません。精密な位置は [JPL Horizons](https://ssd.jpl.nasa.gov/horizons/) で確認してください。
- 渦状腕の形、宇宙の網目構造、CMBの模様は模式図です。実際の観測マップではありません。
- 探査機の現在距離、最遠方銀河の記録、系外惑星の数など、変わりやすい情報は公開時点での推定を含みます。
- 質量のある物体は光速に到達できません。自由飛行の「光速」は仮想の設定です。
- 仮説モードの内容に、科学的な裏付けはありません。
